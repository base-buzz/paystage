Safety tools for AI agent payments

PayStage sits in front of an agent's wallet and answers one question before money moves: should this payment happen? Preflight checks return pay, review, or do_not_pay.

Tools

Small, focused pieces that compose into a payment safety layer.

MCP payment preflight

Available now

An MCP server that evaluates a proposed x402 payment against a local policy file and returns a verdict before the agent signs anything. 

npx @paystage/preflight

Published on npm. Non-interactive variant: npx -y @paystage/preflight.

npm: @paystage/preflight · GitHub: base-buzz/paystage

Example policy.json:

{
  "version": 1,
  "max_amount": { "value": "1.00", "asset": "USDC", "decimals": 6 },
  "allowed_pay_to": ["0x209693Bc6afc0C5328bA36FaF03C514EF312287C"],
  "allowed_networks": ["eip155:8453", "eip155:84532"],
  "unknown_payee": "review"
}

Outstanding-auth watch

Available soon

Watches for payments that are authorized but never settled, so an agent doesn't double-pay or leave funds in limbo.

Farcaster approve mini-app

Available soon

A mini-app for approving or rejecting a pending agent payment from a phone, instead of auto-paying.

Dead-seller watch

Available soon

Flags payees that stop responding or stop settling, and routes new payments to review.

MCP listing provenance receipt

Available soon

A signed receipt tying an MCP listing to its source, so an agent can tell a real listing from a lookalike.

Micro-escrow

Roadmap

Small-value escrow for agent-to-agent payments, released on delivery or timeout.

Publish-and-register one-shot

Roadmap

One command to publish an MCP server and register it with a provenance receipt.
