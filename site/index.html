Tools

Small, focused pieces that compose into a payment safety layer.

MCP payment preflight

Available now

An MCP server that evaluates a proposed x402 payment against a local policy file and returns a verdict before the agent signs anything. 

npx -y @paystage/mcp

Install the umbrella server. Tool: evaluate_mcp_payment.

npm: @paystage/mcp · GitHub: base-buzz/paystage

Hosted pay-per-call HTTP API is live on Base mainnet at https://api.paystage.xyz (eip155:8453, USDC, payTo treasury) and on Base Sepolia at https://sepolia.api.paystage.xyz. Price $0.002 USDC per call.

Example policy.json:

{
  "version": 1,
  "max_amount": { "value": "1.00", "asset": "USDC", "decimals": 6 },
  "allowed_pay_to": ["0x209693Bc6afc0C5328bA36FaF03C514EF312287C"],
  "allowed_networks": ["eip155:8453", "eip155:84532"],
  "unknown_payee": "review"
}

Outstanding-auth watch

Available now

Watches for payments that are authorized but never settled, so an agent doesn't double-pay or leave funds in limbo. 

npx -y @paystage/mcp

Tools: list_outstanding_auths, evaluate_outstanding_auths.

npm: @paystage/mcp · GitHub: base-buzz/paystage

HIP-3 / trade.xyz trade preflight

Available now

A local policy gate for HIP-3 perp trades on trade.xyz. Evaluates a proposed order against your policy and returns a verdict before the agent places anything. 

npx -y @paystage/mcp

Tool: evaluate_hip3_trade. Decisions: allow, review, do_not_trade.

npm: @paystage/trade-preflight · npm: @paystage/mcp

Not financial advice. A local policy gate only — it does not place orders or recommend trades.

Farcaster approve mini-app

Available soon

A mini-app for approving or rejecting a pending agent payment from a phone, instead of auto-paying.

Dead-seller watch

Available soon

Flags payees that stop responding or stop settling, and routes new payments to review.

MCP listing provenance receipt

Available soon

A signed receipt tying an MCP listing to its source, so an agent can tell a real listing from a lookalike.
