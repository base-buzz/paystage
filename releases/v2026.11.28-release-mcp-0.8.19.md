## Published

- `@paystage/mcp@0.8.19`
- `@paystage/preflight@0.6.1`

Both had been serving a `dist/` the repository no longer produces, so npm refused a republish until the versions moved. Verified after the fact:
`assert-artifact --latest` reports "is what the repo says" for each.

`@paystage/n8n` was named in the first attempt and failed with **E404** — npm does not let a Trusted Publisher create a new scoped package name,
so its first publish belongs to the operator's npm account, and it stays private until then.
